# Zero-shot spike

The live spike script is throwaway and is not in this repository. CI never
calls hosted or local model servers.

This tree therefore has no ROC AUC or catch-rate numbers. The 0.1.0 README
uses `SystemOne.local` (Laya `english`) as the illustrative cheap typed-decision
backend with an **application-chosen, non-default** threshold. Those figures
are not evaluation results; Milestone 6 publishes measured defaults.
