# Zero-shot spike

The live spike script is throwaway and is not in this repository. CI never
calls hosted or local model servers.

This tree therefore has no ROC AUC or catch-rate numbers. The README
uses a TypeSafe model id such as `jev-latest` as the illustrative decision
judge with an **application-chosen, non-default** threshold. Those figures
are not evaluation results. 1.0 publishes no measured defaults.
